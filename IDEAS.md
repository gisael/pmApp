# Future Feature Ideas

A collection of potential improvements for Vibe PM.

## Quick Wins

### Due Dates
- Date picker on task creation/edit
- Display due date on card
- Overdue highlighting (red border/text for past due)
- "Due today" and "Due soon" indicators

### Keyboard Shortcuts
- `N` - New task
- `/` - Focus search
- `?` - Show shortcut help modal
- `Esc` - Close modals/cancel edit
- Arrow keys - Navigate between tasks

### Task Search/Filter
- Filter bar above kanban board
- Real-time search by task title
- Filter by priority level
- Clear filter button

### Archive Column
- Fourth column for archived tasks
- Auto-archive completed tasks after X days
- "Archive all done" button
- Restore from archive

## Power Features

### Tags/Labels
- Color-coded tags (BUG, FEATURE, DOCS, URGENT, etc.)
- Multiple tags per task
- Filter by tag
- Custom tag creation

### Subtasks
- Checklist items within a task card
- Progress indicator (3/5 complete)
- Expand/collapse subtask list
- Convert subtask to full task

### Task Stats Dashboard
- Completion rate percentage
- Tasks per priority breakdown
- Tasks completed this week
- Velocity tracking

### Export/Import
- Download all tasks as JSON
- Import tasks from JSON
- Export to CSV for spreadsheets
- Backup/restore functionality

## Quality of Life

### Undo Delete
- Toast notification on delete
- "UNDO" button with countdown
- Undo stack for multiple actions

### Keyboard Navigation
- Arrow keys to move focus between tasks
- Enter to edit focused task
- Space to toggle quick todo
- Tab to move between columns

### Collapse Columns
- Click column header to minimize
- Show only count when collapsed
- Remember collapsed state

### Compact View Toggle
- Denser layout option
- Hide descriptions in compact mode
- More tasks visible at once

## Advanced Features

### Multiple Boards/Projects
- Sidebar with project list
- Switch between projects
- Project-specific settings

### Time Tracking
- Start/stop timer on tasks
- Total time spent display
- Time estimates vs actual

### Pomodoro Timer
- Built-in pomodoro widget
- Link timer to current task
- Break reminders

### Recurring Tasks
- Daily/weekly/monthly repeat
- Auto-create on schedule
- Skip/complete options

### Dark/Light Theme Toggle
- System preference detection
- Manual toggle in header
- Theme persistence

### Drag to Reorder Columns
- Customize column order
- Hide unused columns
- Add custom columns
